Winter time is time for the start of a new project :-) I published an early draft (2021.0.1) of my End-to-End Machine Learning Project Journey:

![_config.yml]({{ site.baseurl }}/images/01_end_to_end_machine_learning_project_journey.png){:class="img-posts"}

The goal is to provide Jupyter notebooks that should serve as a template and guide for your end-to-end journey within a machine learning project.

The journey consists of several steps. Each step is described in detail and offers (depending on the related scope)

* questionnaires and checklists
* comparisons about approaches with code snippets and references to further resources
* documentation templates

For more details visit my github project: [https://github.com/anjakuchenbecker/end_to_end_machine_learning_project_journey](https://github.com/anjakuchenbecker/end_to_end_machine_learning_project_journey).
